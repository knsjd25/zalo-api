Fruit Match

Data Deletion Instructions

How to request deletion of Fruit Match data.

Open Game Privacy Policy Data Deletion Terms

1. Overview

This page explains how users can request deletion of data related to Fruit Match.

The basic version of Fruit Match is a lightweight browser-based H5 game and does not require account registration or Facebook Login.

2. How to Request Data Deletion

To request data deletion, please send an email to:

Email: yilunfan155@gmail.com

3. Email Format

Please include the following information in your request:

  • Subject: Fruit Match Data Deletion Request
  • Game Name: Fruit Match
  • Request Type: Data Deletion
  • Related user ID, share ID, or email: if applicable

4. What We Will Delete

If server-side data associated with your request exists, we will delete or anonymize it within a reasonable period after verifying the request.

Possible data may include:

  • Server-side share records, if any
  • Game session records, if any
  • Account or login data, if such features are added in the future

5. Local Browser Data

Some game data may be stored locally in your browser, such as score, moves, or temporary progress. This local data is stored on your own device.

You can delete it by clearing your browser’s site data, cache, or local storage.

6. If No Server-Side Data Exists

If the basic version of the Game has not stored any server-side personal data about you, we will inform you that there is no server-side personal data to delete.

7. Facebook or Platform Settings

If you accessed the Game through Facebook or another platform, you may also remove the app or website connection from your platform account settings.

8. Contact

For deletion requests or questions, contact us at:

Email: yilunfan155@gmail.com
